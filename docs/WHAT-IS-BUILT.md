4. Sends "Welcome to Rankall Pro" email to customer
5. Posts Slack notification
6. Records referral conversion if applicable
7. Redirects to `/dashboard?upgraded=true`

### The 5 query templates

Generated from the input (e.g. "best dentist in Chicago"):

1. `[raw input]` (verbatim, city appended if missing)
2. `top rated [base] [city]`
3. `best [base] [city] near me`
4. `[base] [city] reviews`
5. `highest rated [base] [city]`

Where `[base]` = input with leading "best"/"top rated"/"top" stripped.

### How the score works

Each platform gets all 5 queries. For each query, `detectBusinessMention` checks whether the AI's response mentions the business (normalized substring match, with fuzzy fallback for name variants). The platform's `mentionRate` = fraction of queries where the business was mentioned (0 to 1). The overall score = sum of (weight × mentionRate) for responding platforms / sum of weights of responding platforms × 100, rounded. Failed or timed-out platforms are excluded from both numerator and denominator so a single timeout can't swing the score.

### How competitors are detected and scored

Competitor names are extracted from all platform responses using regex patterns (bold markdown, recommendation phrases, numbered lists). Names are filtered against a ~70-entry directory blacklist (Yelp, Google, etc.), the target business itself, and generic words. Name variants are normalized by lowercasing, stripping punctuation and entity suffixes (LLC, Inc), and grouping on the first two words — so "Anderson Window & Gutter Cleaning" and "Anderson Window Cleaning LLC" merge into one competitor. Each valid competitor is scored through the same weighted formula as the target. The highest-scoring competitor is selected as the "top competitor."

## 5. Outreach Dashboard

**Location:** `/dashboard/outreach` — admin-only (`useAdminGuard()`), not in any customer nav.

### Buttons and what they do

**Setup:**
- Industry typeahead (from categories list, filtered by country)
- Country dropdown (14 countries)
- City + State inputs
- **"Find Targets"** — calls `/api/outreach/find-targets`, returns list of businesses

**Bulk actions (appear after targets loaded):**
| Button | What it does |
|--------|-------------|
| Find All Emails | Batch-calls `/api/outreach/find-email` for targets without emails (batches of 5) |
| Scan All | Batch-calls `/api/outreach/run-scan` for unsscanned targets |
| Send All | Batch-calls `/api/outreach/send-email` for scanned targets with email |
| Export CSV | Client-side download |

**Per-row:**
- Find Email / Run Scan / Check Score / Rescan / Send Email — contextual per status
- "Scan on rankall.io" link for the main scan page

### CSV export columns

`business_name, email, city, state, industry, address, phone, website, overall_score, mentioned_count, top_competitor, competitor_score, competitor_platform_count, report_url, scan_id`

Only exports rows that have both an email and an overall_score.

### What's hardcoded

- Batch size: 5 (hardcoded)
- Targets persist to localStorage (key: `rankall_outreach_targets`)
- 7-day scan cache: repeat scans of the same business+city return stored result
- Rescan button sends `force: true` to bypass cache
